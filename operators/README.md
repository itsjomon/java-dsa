# Operators in Java

Symbols that tell the compiler to perform some operation

## Example:

```java
sum = a + b;

// a and b are operands
// + is an operator
```

## Types of Operators

- Arithmetic Operators (Binary/Unary)
- Relational Operators
- Logical Operators
- Bitwise Operators
- Assignment Operators
- Ternary Operator (`?:`)
