# Practice Questions

## Qn 1.

What will be the type of result in the following Java code?

```java
byte b = 4;
char c = 'a';
short s = 512;
int i = 1000;
float f = 3.14f;
double d = 99.9954;

result = (f * b) + (i % c) - (d * s);

// (Hint: Look at the largest data type among these)

// Answer: The result variable will be of `double` type because of type conversion
```

## Qn 2.

Will the following statement give any error in Java?

```java
int $ = 24;

// Answer: No, the statement will not give any error. Names of variables are called identifiers in Java. Identifier rule says, identifiers can start with any alphabet or underscore ("_") or dollar ("$"). According to the rule the given variable name is a valid identifier.
```
